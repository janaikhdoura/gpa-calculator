# حاسبة معدل الفصل الدراسي 📚

موقع ويب بسيط وسهل الاستخدام لحساب معدل الفصل الدراسي (GPA) للطلاب الجامعيين.

## الميزات ✨

- ✅ **إضافة المقررات**: أضف المقررات الدراسية بسهولة مع اسم المقرر والساعات المعتمدة والتقدير
- ✅ **حساب المعدل**: احسب معدل الفصل الدراسي على مقياس 4.0 تلقائياً
- ✅ **حذف المقررات**: احذف المقررات بشكل فردي أو احذف جميع المقررات دفعة واحدة
- ✅ **واجهة عربية**: واجهة كاملة باللغة العربية
- ✅ **متوافق مع الهاتف**: تصميم مستجيب يعمل على جميع الأجهزة
- ✅ **حفظ البيانات**: حفظ تلقائي للمقررات باستخدام localStorage
- ✅ **تصميم حديث**: واجهة نظيفة وجميلة وسهلة الاستخدام

## كيفية الاستخدام 🎓

1. **أدخل بيانات المقرر**:
   - اسم المقرر (مثل: الرياضيات 101)
   - عدد الساعات المعتمدة (1-6 ساعات)
   - التقدير الذي حصلت عليه (من A+ إلى F)

2. **اضغط على زر "إضافة مقرر"** لإضافة المقرر إلى القائمة

3. **كرر العملية** لإضافة جميع مقررات الفصل الدراسي

4. **اضغط على زر "احسب المعدل"** لحساب معدلك الجامعي

5. **انظر النتيجة**:
   - إجمالي الساعات المعتمدة
   - إجمالي النقاط
   - معدل الفصل الدراسي (GPA)

## طريقة الحساب 🧮

معدل الفصل الدراسي (GPA) = إجمالي النقاط / إجمالي الساعات المعتمدة

حيث:
- **النقاط** = التقدير × الساعات المعتمدة

### مثال:
- مقرر رياضيات: 4.0 × 3 ساعات = 12 نقطة
- مقرر فيزياء: 3.7 × 4 ساعات = 14.8 نقطة
- مقرر كيمياء: 3.0 × 3 ساعات = 9 نقاط

المعدل = (12 + 14.8 + 9) / (3 + 4 + 3) = 35.8 / 10 = 3.58
